# FS25_AdjustSuite
AdjustSuite for Farming Simulator 2025

This mod lets you adjust all vehicles and attachments however you need. Real: +20% to -20% (in 5% increments), Unreal: +200% to -80% (in 20% increments), Extreme: +800% (in 100% increments). By default, only “Real” is enabled. This setting can be changed in modSettings, where you can also adjust the price, individual modules, and the display in the help menu (the file is created when you first launch the mod). 

Included modules:
- AFV - Adjust Fill Volume
- AMP - Adjust Motor Power
- AWS - Adjust Working Speed
- AWW - Adjust Working Width
- APW - Adjust Pickup Width
- ADS - Adjust Driving Speed
- ABP - Adjust Brake Power
- ADR - Adjust Discharge Rate

-----------------------------------------------------------------------

Dieser Mod ermöglicht es dir alles an Fahrzeugen und Anbaugeräten zu verändern, so wie du es brauchst. Real +20% -20% (5% Schritte), Unreal +200% -80% (20% Schritte), Extreme +800% (100% Schritte). Im Standard ist nur Real aktiviert. Diese Einstellung kann in modSettings verändert werden, dort kann auch der Preis, einzelne Module und die Anzeige im Hilfemenü angepasst werden (Datei erstellt sich beim ersten Starten des Mods).

Enthaltene Module:
- AFV - Füllvolumen
- AMP - Motorleistung
- AWS - Arbeitsgeschwindigkeit
- AWW - Arbeitsbreite
- APW - Pickupbreite
- ADS - Fahrgeschwindigkeit
- ABP - Bremskraft
- ADR - Entladerate
